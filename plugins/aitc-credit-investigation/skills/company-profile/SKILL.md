# 公司基本資料查詢

## 資料來源規則
使用 xbrl-taiwan MCP，禁止網路搜尋財務數字。

## 查詢流程

### 步驟 1：列出公司資訊
```
list_companies(name_filter="台泥")   # 或用股票代碼搜尋
```

### 步驟 2：確認可用財務期間
```
list_periods(company_code="1101")
```

### 步驟 3：取得資料庫結構（如需確認欄位）
```
get_schema()
```

## 輸出格式

```
公司基本資料
─────────────────
公司代碼：[代碼]
可用財務期間：[最早] 至 [最新]，共 [N] 期
產業別：[來自資料庫]
申報範圍：[合併/個別]

資料來源：AITC XBRL 資料庫
⚠️ 如需最新公司資訊，請參閱台灣證交所官方資料。
```
