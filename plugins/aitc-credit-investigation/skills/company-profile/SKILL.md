# 公司基本資料查詢

## FIRST：資料來源

**FIRST:** 呼叫 `xbrl-taiwan` MCP 確認公司是否在資料庫中。

---

## Perfect for

- 開始信用調查前確認公司在資料庫中有資料
- 使用者只知道公司名稱，需要查找股票代碼
- 確認某公司有哪些可用的財務申報期間
- 了解公司的產業別與申報範圍（合併/個別）

## Not ideal for

- 取得財務數字（改用 xbrl-query）
- 生成完整報告（改用 credit-memo）

---

## 查詢流程

**步驟 1：搜尋公司**

```
list_companies(name_filter="台泥")
```

顯示結果給使用者確認是正確的公司後，再繼續。

**步驟 2：查詢可用期間**

```
list_periods(company_code="1101")
```

## 輸出格式

```
公司基本資料
─────────────────────────────────────
公司代碼：[代碼]
可用財務期間：[最早期間] 至 [最新期間]，共 [N] 期
可用期間清單：[Q1, Q2, Q3... 列表]
產業別：[來自資料庫]
申報範圍：[合併報表（CR）/ 個別報表（IR）]

資料來源：AITC XBRL 資料庫
⚠️ 如需最新公司登記資訊，請參閱台灣證交所官方資料。
```

---

## 查無資料時

```
查詢結果：找不到 [公司名稱/代碼] 的資料。

可能原因：
  1. 代碼不存在：請確認股票代碼是否正確
  2. 尚未入庫：該公司 XBRL 申報資料尚未匯入本系統
  3. 輸入錯誤：請嘗試其他關鍵字

建議：使用 list_companies 搜尋相似名稱的公司。
```
