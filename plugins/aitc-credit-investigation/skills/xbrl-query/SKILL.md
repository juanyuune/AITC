# XBRL 財務資料查詢

## 資料來源規則
永遠使用 xbrl-taiwan MCP，禁止網路搜尋。詳見 data-sources skill。

## 查詢流程

### 步驟 1：解析問題
從問題中擷取：
- **公司**：股票代碼或公司名稱（例：台泥、1101、臺灣水泥）
- **期間**：年度 + 季度（例：2024Q3）
- **財務項目**：中文財務名稱

### 步驟 2：確認可用期間
```
list_periods(company_code="XXXX")
```
確認該期間有資料再查詢，避免空結果。

### 步驟 3：查詢財務數字
```
get_company_financials(
    company_code="XXXX",
    period="2024Q3",
    fields=["營業收入"]   # 可選，不填則回傳全部
)
```

### 步驟 4：找不到欄位時
```
list_fields(keyword="營收")   # 用關鍵字搜尋欄位名稱
```

## 常用財務欄位對照

| 查詢用語 | 欄位名稱（zh_name） |
|---|---|
| 現金水位 / 現金 | 現金及約當現金 |
| 應收帳款 | 應收帳款淨額 |
| 總資產 | 資產總計 |
| 總負債 | 負債總計 |
| 股東權益 | 權益總計 |
| 營收 / 業績 | 營業收入 |
| 毛利 | 毛利潤 |
| 營業利益 | 營業利益 |
| 稅後淨利 | 本期淨利 |
| EPS | 基本每股盈餘 |
| 流動資產 | 流動資產合計 |
| 流動負債 | 流動負債合計 |

## 輸出格式

```
[公司簡稱] [年度][季度] [財務項目]：新台幣 [數字，千分位] 元

資料來源：AITC XBRL 資料庫（FinancialStatementXBRL.db）
⚠️ 本數據僅供參考，正式信用決策請經合格分析師複核。
```

**Q4 特別說明：**
若查詢 Q4 數據，必須附加：
「Q4 為全年累計數字（1月至12月），非單季數字。」
