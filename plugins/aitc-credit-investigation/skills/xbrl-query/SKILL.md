# XBRL 財務數字查詢

## FIRST：資料來源

**FIRST:** 呼叫 `xbrl-taiwan` MCP 的 `get_company_financials` 工具。
不得使用網路搜尋取得財務數字。

---

## Perfect for

- 分析師詢問單一公司、單一期間的特定財務數字
- 快速查核某季的現金水位、應收帳款、負債結構
- 取得損益表或現金流量表的原始數字供後續計算

## Not ideal for

- 多季走勢比較（改用 trend-analysis）
- 計算比率（改用 ratio-analysis）
- 比較多家公司（改用 peer-comparison）
- 生成完整報告（改用 credit-memo）

---

## 查詢流程

**步驟 1：解析問題**

從問題中擷取：
- 公司：股票代碼或公司名稱
- 期間：年度 + 季度（例：2024Q3）
- 財務項目：中文財務名稱

**步驟 2：確認可用期間（若期間不明確）**

```
list_periods(company_code="XXXX")
```

⚠️ 確認後，先告知使用者可查詢期間，再繼續。

**步驟 3：查詢財務數字**

```
get_company_financials(
    company_code="XXXX",
    period="2024Q3"
    # fields=["營業收入"]  ← 可選，不填則回傳全部
)
```

**步驟 4：找不到欄位時**

```
list_fields(keyword="營收")
```

顯示搜尋結果給使用者，請其確認正確欄位名稱後再查詢。

## 輸出格式

```
[公司簡稱]（[股票代碼]）[年度][季度] [財務項目]

數值：新台幣 [數字，千分位] 元
資料來源：台灣 XBRL 資料庫 / 合併報表（CR）/ [申報期間]

[若查詢 Q4，加注：⚠️ Q4 為全年累計數字，非單季。]

⚠️ 本資料僅供參考，財務決策請以公司正式公告及合格分析師審查為準。
```
