# 綜合損益表分析

## FIRST：資料來源

**FIRST:** 呼叫 `xbrl-taiwan` MCP 的 `get_company_financials`，
`statement_type="IS"` 篩選損益表欄位。

---

## Perfect for

- 評估公司獲利能力和盈利品質
- 計算毛利率、營業利益率、淨利率
- 比較單季 vs 累計數字
- 追蹤 EPS 趨勢
- 判斷本業獲利與業外損益的關係

## Not ideal for

- 資產負債結構（改用 balance-sheet）
- 現金流量（改用 cash-flow）
- 多季趨勢（改用 trend-analysis）

---

## ⚠️ 台灣 XBRL 損益表特殊說明

台灣 XBRL 損益表同時揭露**單季數字**與**累計 YTD 數字**：
- **Q3 單季**：7月–9月的獨立數字
- **Q1–Q3 累計**：1月–9月的累計數字

**Q4 為全年累計（1/1–12/31）**，無法直接取得 Q4 單季數字。
Q4 單季 = 全年累計 − 前三季累計（推算值，非申報數）。

---

## 核心欄位

| 欄位 | 信用意義 |
|---|---|
| 營業收入 | 主要業務規模 |
| 營業成本 | 直接生產成本效率 |
| 毛利潤 | 定價能力與成本控制 |
| 營業費用 | 銷管研費用控制 |
| 營業利益 | 本業獲利核心指標 |
| 業外收支 | 投資收益、利息費用等 |
| 本期淨利 | 最終獲利數字 |
| 基本每股盈餘 | EPS，股東報酬指標 |

---

## 查詢流程

**步驟 1：查詢損益表**

```
get_company_financials(
    company_code="XXXX",
    period="2024Q3",
    statement_type="IS"
)
```

**步驟 2：呈現結果並說明單季 vs 累計的區別**

顯示數字後，提示使用者：
> 需要計算毛利率、淨利率等比率嗎？輸入 `ratio [代碼] [期間]`。

## 輸出格式

```
[公司]（[代碼]）[期間] 損益表摘要

【Q3 單季】
  營業收入：NT$ [數字]
  毛利潤：NT$ [數字]（毛利率 [X]%）
  營業利益：NT$ [數字]（營業利益率 [X]%）
  本期淨利：NT$ [數字]（淨利率 [X]%）
  基本 EPS：NT$ [X.XX] 元

【Q1–Q3 累計】
  營業收入：NT$ [數字]
  本期淨利：NT$ [數字]
  累計 EPS：NT$ [X.XX] 元

資料來源：台灣 XBRL 資料庫 / 合併報表（CR）
⚠️ 本資料僅供參考，財務決策請以公司正式公告及合格分析師審查為準。
```
