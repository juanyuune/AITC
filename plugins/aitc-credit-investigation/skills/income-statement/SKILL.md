# 綜合損益表分析

## 資料來源規則
使用 xbrl-taiwan MCP，禁止網路搜尋。詳見 data-sources skill。

## 核心欄位

| 欄位 | 說明 |
|---|---|
| 營業收入 | 主要業務收入 |
| 營業成本 | 直接生產成本 |
| 毛利潤 | 營收扣除直接成本 |
| 營業費用 | 銷售、管理、研發費用 |
| 營業利益 | 本業獲利能力 |
| 業外收支 | 利息、投資損益等 |
| 稅前淨利 | 繳稅前獲利 |
| 本期淨利 | 最終獲利數字 |
| 基本每股盈餘 | EPS |

## 查詢方式
```
get_company_financials(
    company_code="XXXX",
    period="2024Q3",
    statement_type="IS"
)
```

## Q4 特別注意
**Q4 損益數字為全年累計（1月至12月），非單季。**
計算 Q4 單季數字需以「全年 − Q1 − Q2 − Q3」。

## 分析重點

1. **毛利率**：(毛利潤 ÷ 營業收入) × 100%
2. **營業利益率**：(營業利益 ÷ 營業收入) × 100%
3. **淨利率**：(本期淨利 ÷ 營業收入) × 100%
4. **費用比率**：營業費用 ÷ 營業收入，觀察費用控制能力

## 輸出格式

```
[公司] [期間] 損益表摘要

營業收入：NT$ XXX
毛利潤：NT$ XXX（毛利率 X%）
營業利益：NT$ XXX（營業利益率 X%）
本期淨利：NT$ XXX（淨利率 X%）
EPS：NT$ X.XX

資料來源：AITC XBRL 資料庫
⚠️ 本資料僅供參考，正式信用決策請經合格分析師複核。
```
