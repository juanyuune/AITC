# 同業比較分析

## 資料來源規則
使用 xbrl-taiwan MCP，禁止網路搜尋。詳見 data-sources skill。

## 查詢方式

```
compare_companies(
    company_codes=["2303", "2344", "2454"],
    field="營業收入",
    period="2024Q3"
)
```

## 分析流程

1. 確認所有公司在資料庫中有該期間數據
2. 查詢同一期間、同一欄位的數值
3. 排序並計算相對規模
4. 識別最高值、最低值、中位數
5. 計算查詢公司相對於同業的位置

## 常用比較指標

| 類別 | 指標 |
|---|---|
| 規模 | 資產總計、營業收入 |
| 獲利 | 毛利率、淨利率、ROE |
| 償債 | 負債比率、流動比率 |
| 現金 | 現金及約當現金 |

## 注意事項

- 只比較**同一期間**的數字，避免跨期比較失真
- 不同產業的公司，比率基準不同，需謹慎比較
- Q4 數字為全年累計，可跨公司比較但需標註

## 輸出格式

```
[期間] [財務項目] 同業比較

公司代碼 | 數值 | 同業排名
─────────────────────────
XXXX    | NT$ XXX  | 第 X 名
XXXX    | NT$ XXX  | 第 X 名
XXXX    | NT$ XXX  | 第 X 名

[查詢公司] 位於同業 [前X% / 中段 / 後X%]

資料來源：AITC XBRL 資料庫
⚠️ 比較結果僅供參考，正式信用決策請經合格分析師複核。
```
