# 同業比較分析

## FIRST：資料來源

**FIRST:** 先嘗試 `compare_companies` MCP 工具（單次呼叫最有效率）。
若部分公司無資料，再用個別 `get_company_financials` 補查。

---

## Perfect for

- 評估目標公司在同業中的財務定位
- 找出行業中財務表現最佳/最差的公司
- 支援信用調查的相對風險評估
- 識別業務規模差距

## Not ideal for

- 不同產業之間的比較（比率基準不同）
- 時間序列分析（改用 trend-analysis）

---

## 查詢流程

**步驟 1：先嘗試 compare_companies**

```
compare_companies(
    company_codes=["1101", "1102", "1103"],
    field="營業收入",
    period="2024Q3"
)
```

**步驟 2：確認哪些公司有資料**

若部分公司回傳空值，呼叫 `list_periods` 確認是「此期間無資料」
還是「完全未入庫」——兩者原因不同，說明給使用者聽。

**步驟 3：整合結果並排名**

顯示結果後，詢問使用者：
> 需要計算比率（如毛利率、負債比率）進行更深入的同業比較嗎？

---

## 查無同業資料時

```
[公司代碼] 目前未收錄於 XBRL 資料庫（list_periods 回傳空陣列）。

建議替代方案：
  1. 使用 list_companies 確認資料庫中有哪些同業公司
  2. 改用 [目標公司] 的多年趨勢自身比較
  3. 聯繫 AITC 資料團隊確認入庫計畫
```

---

## ⚠️ 跨產業比較注意事項

不同產業的財務比率基準差異很大：
- 金融業：負債比率天然偏高（超過 90% 是正常的）
- 生技業：研發費用高，短期虧損常見
- 零售業：存貨週轉率比製造業高很多

若比較對象跨產業，必須在輸出中說明此限制。

---

## 輸出格式

```
同業比較｜[財務項目]｜[期間]

  排名  公司名稱  代碼   數值          單位    備注
  ─────────────────────────────────────────────
  1     [公司]   [代碼]  [數字，千分位]  百萬元  [報告範圍]
  2     [公司]   [代碼]  [數字，千分位]  百萬元
  —     [公司]   [代碼]  無資料                  未收錄於資料庫

觀察：[一句話，說明差距大小與市場定位]

⚠️ 本資料僅供參考，財務決策請以公司正式公告及合格分析師審查為準。
```
