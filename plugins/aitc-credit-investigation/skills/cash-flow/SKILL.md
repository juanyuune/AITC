# 現金流量表分析

## 資料來源規則
使用 xbrl-taiwan MCP，禁止網路搜尋。詳見 data-sources skill。

## 核心欄位

| 欄位 | 說明 | 信用意義 |
|---|---|---|
| 營業活動之淨現金流入（出） | 本業現金產生力 | 正值且穩定最佳 |
| 投資活動之淨現金流入（出） | 資本支出與投資 | 擴張期通常為負 |
| 籌資活動之淨現金流入（出） | 借款與還款 | 觀察融資依賴度 |
| 本期現金及約當現金增加（減少） | 淨現金變化 | |

## 查詢方式
```
get_company_financials(
    company_code="XXXX",
    period="2024Q3",
    statement_type="CF"
)
```

## 分析重點

1. **營業現金流**：是否持續為正？能否支應本業運作？
2. **自由現金流**：營業現金流 − 資本支出
3. **現金轉換能力**：淨利 vs 營業現金流的差距
4. **融資依賴**：籌資現金流長期為正代表持續舉債

## 警示訊號

- 淨利為正但營業現金流持續為負 → 應收帳款或存貨異常堆積
- 自由現金流長期為負 → 資本支出壓力大，注意債務風險
- 籌資現金流連續大幅流入 → 短期融資依賴，需追蹤到期結構

## 輸出格式

```
[公司] [期間] 現金流量摘要

營業活動現金流：NT$ XXX [正常 / 注意]
投資活動現金流：NT$ XXX
籌資活動現金流：NT$ XXX
本期現金淨變化：NT$ XXX

自由現金流（估算）：NT$ XXX

資料來源：AITC XBRL 資料庫
⚠️ 本資料僅供參考，正式信用決策請經合格分析師複核。
```
