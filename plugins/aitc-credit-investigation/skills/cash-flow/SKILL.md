# 現金流量表分析

## FIRST：資料來源

**FIRST:** 呼叫 `xbrl-taiwan` MCP 的 `get_company_financials`，
`statement_type="CF"` 篩選現金流量表欄位。

---

## Perfect for

- 評估企業本業現金產生能力（不受會計估計影響）
- 分析資本支出規模與擴張策略
- 了解融資依賴程度
- 判斷淨利品質（淨利 vs 營業現金流的差距）
- 計算自由現金流

## Not ideal for

- 損益分析（改用 income-statement）
- 資產負債分析（改用 balance-sheet）

---

## 三大現金流的信用意義

| 現金流項目 | 健康訊號 | 警示訊號 |
|---|---|---|
| 營業活動現金流 | 持續為正，接近淨利 | 持續為負，遠低於淨利 |
| 投資活動現金流 | 合理資本支出 | 過度擴張或大額收購 |
| 籌資活動現金流 | 適度融資配合成長 | 長期大量舉債 |

**警示訊號解讀：**
- 淨利為正但營業現金流持續為負 → 應收帳款或存貨異常堆積
- 自由現金流長期為負 → 資本支出壓力大，注意債務風險
- 籌資現金流連續大幅流入 → 短期融資依賴，需追蹤到期結構

## 查詢流程

**步驟 1：查詢現金流量表**

```
get_company_financials(
    company_code="XXXX",
    period="2024Q3",
    statement_type="CF"
)
```

**步驟 2：計算自由現金流（如有資本支出數字）**

自由現金流 = 營業活動現金流 − 資本支出

**步驟 3：呈現結果並標注任何警示訊號**

---

## ⚠️ Q4 說明

現金流量表 Q4 數字為全年累計（1/1–12/31），非 Q4 單季。

---

## 輸出格式

```
[公司]（[代碼]）[期間] 現金流量摘要

【三大現金流（累計）】
  營業活動現金流量：[+/-] NT$ [數字]  [正常 ✅ / 注意 ⚠️]
  投資活動現金流量：[+/-] NT$ [數字]
  籌資活動現金流量：[+/-] NT$ [數字]

【期末現金】
  期末現金及約當現金：NT$ [數字]

【自由現金流（估算）】
  NT$ [數字]（= 營業現金流 − 資本支出）

【信用觀察】
  [一到兩句：現金產生能力評估 + 資本支出水位說明]

⚠️ 本資料僅供參考，財務決策請以公司正式公告及合格分析師審查為準。
```
