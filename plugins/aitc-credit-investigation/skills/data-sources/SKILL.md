# 資料來源優先順序規則

## FIRST：資料來源優先順序（每次查詢必須遵守）

**第一順位：xbrl-taiwan MCP（必須優先使用）**

在回答任何財務數字前，先呼叫 xbrl-taiwan MCP 工具。

```
可用 MCP 工具：
  get_schema            → 檢查資料庫結構
  list_companies        → 列出所有公司（支援名稱篩選）
  list_periods          → 查詢公司可用申報期間
  list_fields           → 搜尋可用財務欄位
  get_company_financials → 查詢單一公司單一期間
  get_trend_data        → 查詢多期趨勢資料
  compare_companies     → 同業比較
  run_read_query        → 自訂 SELECT 查詢
```

**嚴格禁止：使用網路搜尋取得財務數字**

網路搜尋結果可能過時、不可追溯，且無法滿足信用調查的資料品質要求。

**資料庫查無資料時：明確告知，不猜測**

若 MCP 回傳 row_count: 0，告知使用者「此公司/期間尚未收錄」，
提供 list_periods 結果作為可用替代方案。

## 查詢參數格式

- **公司代碼**：四位數股票代碼，例如 `"2303"`、`"1101"`
- **期間**：`"2024Q3"`、`"2024Q4"`、`"2024Q1"` 等格式
- **欄位名稱**：使用中文欄位名稱，例如 `"營業收入"`、`"資產總計"`
- **季度格式**：資料庫存儲為字串 `"Q3"`，非整數

---

## ⚠️ Q4 全年累計警示（每次涉及 Q4 必須標注）

台灣 XBRL 申報規範：
- Q1、Q2、Q3：**單季數字**（可直接比較）
- **Q4：全年累計數字（1月至12月）**，非單季數字

每次輸出包含 Q4 數據時，必須加注：
> ⚠️ Q4 數據為全年累計值（1/1–12/31），非單季數字。

---

## 免責聲明（每份財務輸出必須包含）

每次回傳財務數字後，結尾必須附上：

> ⚠️ 本資料僅供參考，財務決策請以公司正式公告（MOPS 公開資訊觀測站）及合格分析師審查為準。
