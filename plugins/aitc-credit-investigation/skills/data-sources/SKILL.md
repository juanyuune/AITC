# 資料來源優先順序規則

## ⚠️ 核心規則（每次查詢必須遵守）

**優先順序：**

1. **第一順位：xbrl-taiwan MCP（必須優先使用）**
   - 所有台灣上市公司財務數字必須透過 xbrl-taiwan MCP 連接器查詢
   - 資料來源：AITC 本地端 FinancialStatementXBRL.db
   - 資料依據：台灣證交所正式 XBRL 申報文件

2. **嚴禁使用網路搜尋取得財務數字**
   - 網路搜尋結果可能過時、不準確
   - 無法滿足信用調查所需的可追溯性要求

3. **資料庫查無資料時的處理**
   - 明確告知使用者：「此公司/期間尚未匯入 XBRL 資料庫」
   - 不可臆測、估算或引用其他來源的數字

## 可用 MCP 工具

| 工具 | 用途 |
|---|---|
| `get_schema` | 檢查資料庫結構 |
| `list_companies` | 列出所有公司 |
| `list_periods` | 查詢公司可用期間 |
| `list_fields` | 搜尋可用財務欄位 |
| `get_company_financials` | 查詢單一公司單一期間財務數字 |
| `get_trend_data` | 查詢多期趨勢數據 |
| `compare_companies` | 同業比較 |
| `run_read_query` | 自訂 SQL 查詢（SELECT 限定） |

## 查詢參數格式

- **公司代碼**：台灣股票代碼，例如 `"2330"`
- **期間**：`"2024Q3"`、`"2024Q4"`、`"2024Q1"` 等格式
- **欄位名稱**：使用中文欄位名稱，例如 `"營業收入"`、`"資產總計"`

## ⚠️ Q4 全年累計警示

Q4 數據為全年累計值（1月至12月），非單季數字。
每次輸出涉及 Q4 數據時，必須標註此警示。
