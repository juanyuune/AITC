# 多季趨勢分析

## 資料來源規則
使用 xbrl-taiwan MCP，禁止網路搜尋。詳見 data-sources skill。

## ⚠️ Q4 資料限制（必讀）

台灣 XBRL 申報格式：
- Q1、Q2、Q3：**單季可比較數字**
- Q4：**全年累計數字**（非單季）

進行趨勢分析時：
1. Q1→Q2、Q2→Q3 可計算季成長率
2. **Q4 不可與 Q1-Q3 直接比較成長率**
3. 每次輸出必須標註 Q4 限制

## 查詢方式

### 方式一：指定期間清單
```
get_trend_data(
    company_code="XXXX",
    fields=["營業收入", "本期淨利"],
    periods=["2024Q1", "2024Q2", "2024Q3", "2024Q4"]
)
```

### 方式二：自動取最近 N 期
```
get_trend_data(
    company_code="XXXX",
    fields=["營業收入"],
    last_n_periods=8
)
```

## 分析流程

1. 取得 Q1–Q4（或多年）原始數字
2. 計算 Q1→Q2、Q2→Q3 季成長率
3. 判斷整體走勢：穩定成長 / 持平 / 下降 / 波動不穩
4. 標註異常：單季變動超過 ±30% 特別說明
5. 若跨年，進行年度比較

## 輸出格式

```
[公司] [年度] [財務項目] 走勢

Q1：NT$ XXX
Q2：NT$ XXX（較Q1：+X%）
Q3：NT$ XXX（較Q2：-X%）
Q4：NT$ XXX（全年累計，非單季數字）

整體判斷：[穩定成長 / 持平 / 下降 / 波動不穩]
[如有異常波動，特別說明原因]

資料來源：AITC XBRL 資料庫
⚠️ Q4 為全年累計數字，非單季。趨勢判斷僅供參考，正式信用決策請經合格分析師複核。
```
