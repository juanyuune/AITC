# 財務比率分析

## 資料來源規則
使用 xbrl-taiwan MCP 取得原始數字後計算，禁止網路搜尋。

## 計算前必須先取得原始數字
```
get_company_financials(company_code="XXXX", period="2024Q3")
```

## 四大類比率

### 一、償債能力比率
| 比率 | 公式 | 台灣製造業參考區間 |
|---|---|---|
| 負債比率 | 負債總計 ÷ 資產總計 | < 40% 穩健、> 60% 高風險 |
| 流動比率 | 流動資產 ÷ 流動負債 | > 150% 穩健、< 100% 警示 |
| 速動比率 | (流動資產 − 存貨) ÷ 流動負債 | > 100% 穩健 |
| 利息保障倍數 | 營業利益 ÷ 利息費用 | > 3x 穩健、< 1.5x 警示 |

### 二、獲利能力比率
| 比率 | 公式 | 說明 |
|---|---|---|
| 毛利率 | 毛利潤 ÷ 營業收入 | 依產業差異大，需同業比較 |
| 營業利益率 | 營業利益 ÷ 營業收入 | 本業獲利效率 |
| 淨利率 | 本期淨利 ÷ 營業收入 | 正值且穩定為佳 |
| ROE | 本期淨利 ÷ 權益總計 | > 10% 為佳 |
| ROA | 本期淨利 ÷ 資產總計 | > 5% 為佳 |

### 三、效率比率
| 比率 | 公式 | 說明 |
|---|---|---|
| 應收帳款週轉率 | 營業收入 ÷ 應收帳款淨額 | 越高越佳 |
| 存貨週轉率 | 營業成本 ÷ 存貨 | 越高越佳 |

### 四、成長性
| 指標 | 公式 | 說明 |
|---|---|---|
| 營收年增率 | (本期 − 去年同期) ÷ 去年同期 | 年度比較 |
| 淨利年增率 | (本期 − 去年同期) ÷ 去年同期 | 年度比較 |

## 注意事項

- 上述區間為台灣**製造業**參考值，非製造業（生技、營建、金融、旅遊）門檻不同
- 若產業非製造業，輸出中必須標明「比率區間為一般參考值，未依產業別調整」
- 比率計算後只作為參考標籤，**不可直接用於核貸決策**

## 輸出格式

```
[公司] [期間] 財務比率分析

【償債能力】
負債比率：X%　[穩健 / 中等 / 高風險]
流動比率：X%　[穩健 / 中等 / 警示]

【獲利能力】
毛利率：X%
營業利益率：X%
淨利率：X%　[正常 / 留意 / 風險]
ROE：X%

【注意事項】
[如有異常比率，特別說明]

資料來源：AITC XBRL 資料庫
⚠️ 比率區間為一般參考值，正式信用決策請經合格分析師複核。
```
