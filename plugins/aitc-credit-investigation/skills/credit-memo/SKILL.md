# 信用調查報告生成

## FIRST：資料來源

**FIRST:** 所有財務數字來自 `xbrl-taiwan` MCP。
先查資料，後寫報告。禁止憑空生成任何財務數字。

---

## Perfect for

- 信用調查分析師需要完整的一份報告
- 授信決策前的資料整合
- 客戶財務健康度的定期審查

## Not ideal for

- 快速單一數字查詢（改用 xbrl-query）
- 單項分析（改用對應的專門技能）

---

## 生成流程

**步驟 1：確認公司與期間**

```
list_periods(company_code="XXXX")
```

顯示可用期間，請使用者確認報告年度後再繼續。

**步驟 2：取得四季財務數字（分別呼叫）**

```
get_company_financials(company_code="XXXX", period="2024Q1")
get_company_financials(company_code="XXXX", period="2024Q2")
get_company_financials(company_code="XXXX", period="2024Q3")
get_company_financials(company_code="XXXX", period="2024Q4")
```

**步驟 3：取得趨勢數據**

```
get_trend_data(
    company_code="XXXX",
    fields=["營業收入", "本期淨利", "資產總計", "負債總計"],
    last_n_periods=8
)
```

**步驟 4：告知使用者資料已就緒，開始生成報告**

> 已取得 [公司] 2024 年四季財務資料，開始生成信用調查報告...

**步驟 5：生成完整六章節報告**

```
# 信用調查報告
## [公司全名]（股票代碼：[代碼]）
報告日期：[日期]　　最新資料期間：[最新季度]

---

## 一、公司基本資料
[公司全名、代碼、產業別、申報範圍、財報標準、資料期間]

---

## 二、財務概況（近四季）
[資產總計、負債總計、權益總計、負債比率 — 四季對照表]
[營業收入、本期淨利、EPS — 四季累計數字]

---

## 三、關鍵財務比率
[負債比率、流動比率（若可得）、毛利率、淨利率、ROE]
[附台灣製造業參考區間與評估標籤]

---

## 四、多季趨勢分析
[主要指標 Q1–Q4 走勢，標示成長/下降/持平]
⚠️ Q4 損益數字為全年累計，非單季數字

---

## 五、風險評估

綜合風險等級：[🟢 低風險 / 🟡 中等風險 / 🔴 高風險]

五大指標掃描：
  負債比率 > 60%      → [通過 ✅ / 觸發 ❌]
  流動比率 < 1.0x     → [通過 ✅ / 觸發 ❌ / 資料不足 N/A]
  營業現金流 < 0      → [通過 ✅ / 觸發 ❌]
  本期淨利 < 0        → [通過 ✅ / 觸發 ❌]
  營收連兩季降 > 20%  → [通過 ✅ / 觸發 ❌]

[其他觀察事項（非旗標，建議追蹤）]
```
