# 資產負債表分析

## 資料來源規則
使用 xbrl-taiwan MCP，禁止網路搜尋。詳見 data-sources skill。

## 核心欄位

### 資產面
| 欄位 | 說明 |
|---|---|
| 現金及約當現金 | 流動性核心指標 |
| 應收帳款淨額 | 營收品質指標 |
| 存貨 | 庫存管理指標 |
| 流動資產合計 | 短期償債來源 |
| 不動產廠房及設備 | 固定資產規模 |
| 資產總計 | 企業規模基準 |

### 負債面
| 欄位 | 說明 |
|---|---|
| 流動負債合計 | 短期還款壓力 |
| 短期借款 | 短期融資水位 |
| 應付帳款 | 供應商付款條件 |
| 長期借款 | 長期融資結構 |
| 負債總計 | 整體負債規模 |

### 權益面
| 欄位 | 說明 |
|---|---|
| 股本 | 資本規模 |
| 保留盈餘 | 累積獲利能力 |
| 權益總計 | 淨值水位 |

## 查詢方式
```
get_company_financials(
    company_code="XXXX",
    period="2024Q3",
    statement_type="BS"
)
```

## 分析重點

1. **資產結構**：流動資產 vs 非流動資產比例
2. **負債結構**：短期 vs 長期負債比例，是否集中短期
3. **淨值變化**：權益是否穩定成長
4. **現金水位**：現金及約當現金是否足以應付短期負債

## 輸出格式

```
[公司] [期間] 資產負債表摘要

【資產面】
現金及約當現金：NT$ XXX（占總資產 X%）
流動資產合計：NT$ XXX
資產總計：NT$ XXX

【負債面】
流動負債合計：NT$ XXX
負債總計：NT$ XXX（負債比率 X%）

【權益面】
權益總計：NT$ XXX

資料來源：AITC XBRL 資料庫
⚠️ 本資料僅供參考，正式信用決策請經合格分析師複核。
```
