# 資產負債表分析

## FIRST：資料來源

**FIRST:** 呼叫 `xbrl-taiwan` MCP 的 `get_company_financials`，
`statement_type="BS"` 篩選資產負債表欄位。

---

## Perfect for

- 評估企業短期償債能力（流動資產 vs 流動負債）
- 分析負債結構（短期 vs 長期、有息 vs 無息）
- 了解現金水位是否充裕
- 判斷財務結構是否穩健
- 追蹤淨值（股東權益）的季度變化

## Not ideal for

- 獲利能力分析（改用 income-statement）
- 現金流量分析（改用 cash-flow）
- 財務比率計算（改用 ratio-analysis）

---

## 核心欄位

### 資產面
| 欄位 | 信用意義 |
|---|---|
| 現金及約當現金 | 流動性核心，第一道防線 |
| 應收帳款淨額 | 收款品質，過高需追蹤週轉天數 |
| 存貨 | 庫存管理，過高有滯銷風險 |
| 流動資產合計 | 短期償債來源 |
| 不動產廠房及設備 | 固定資產規模 |
| 資產總計 | 企業整體規模基準 |

### 負債面
| 欄位 | 信用意義 |
|---|---|
| 流動負債合計 | 一年內到期的償還壓力 |
| 短期借款 | 短期融資水位，需關注到期結構 |
| 應付帳款 | 供應商付款條件 |
| 長期借款 | 長期融資結構 |
| 負債總計 | 整體負債規模 |

### 權益面
| 欄位 | 信用意義 |
|---|---|
| 股本 | 資本規模 |
| 保留盈餘 | 累積獲利能力 |
| 權益總計 | 淨值水位，承受損失能力 |

## 查詢流程

**步驟 1：查詢資產負債表**

```
get_company_financials(
    company_code="XXXX",
    period="2024Q3",
    statement_type="BS"
)
```

**步驟 2：呈現結果，詢問使用者是否需要進一步分析**

顯示數字後，提示使用者：
> 需要計算財務比率（負債比率、流動比率）嗎？輸入 `ratio [代碼] [期間]`。

---

## 分析重點（依序檢查）

1. **現金水位**：現金及約當現金是否足以應付流動負債？
2. **負債結構**：短期借款比例是否過高？是否集中到期？
3. **淨值趨勢**：股東權益是否季季成長？有無侵蝕？
4. **應付債券**：如有大額應付債券，追蹤到期時程

---

## 輸出格式

```
[公司]（[代碼]）[期間] 資產負債表摘要

【資產面】
  現金及約當現金：NT$ [數字]（占總資產 [X]%）
  應收帳款淨額：NT$ [數字]
  流動資產合計：NT$ [數字]
  資產總計：NT$ [數字]

【負債面】
  流動負債合計：NT$ [數字]
  短期借款：NT$ [數字]
  負債總計：NT$ [數字]（負債比率 [X]%）

【權益面】
  權益總計：NT$ [數字]（自有資本率 [X]%）

【初步判斷】
  [一句話：財務結構穩健 / 負債偏高需追蹤 / 現金水位充裕]

資料來源：台灣 XBRL 資料庫 / 合併報表（CR）
⚠️ 本資料僅供參考，財務決策請以公司正式公告及合格分析師審查為準。
```
