# /ratio — 財務比率分析

計算台灣上市公司的六大財務比率，依台灣產業標準判斷健康區間。

## 流程

1. 解析公司代碼與期間
2. 使用 xbrl-taiwan MCP 取得資產負債表與損益表原始數字
3. 使用 skill: "ratio-analysis" 計算六大比率並給出健康判斷
4. 若資料不足（如 XBRL 未揭露細項），標注「資料不足」而非猜測

## 範例

**輸入：** `ratio 2303 2024Q3`

**輸出：**
```
聯電（2303）2024Q3 財務比率

  負債比率：35.8%  → 穩健 ✅
  流動比率：資料不足（XBRL 申報未揭露流動資產/負債細項）
  毛利率：33.8%
  營業利益率：23.3%
  淨利率：23.9%
  ROE（年化）：15.7%
```
