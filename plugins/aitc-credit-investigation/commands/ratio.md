# /ratio — 財務比率分析

計算台灣上市公司的關鍵財務比率，依台灣產業標準判斷健康區間。

## 流程

1. 解析公司代碼與期間
2. 使用 xbrl-taiwan MCP 取得資產負債表與損益表數字
3. 使用 skill: "ratio-analysis" 計算比率並判斷健康區間
4. 呈現完整比率表，標注異常指標

## 範例

**輸入：** `/ratio 台泥 2024Q3`

**輸出：**
```
台泥 2024Q3 財務比率

負債比率：X%　[穩健]
流動比率：X%　[穩健]
毛利率：X%
淨利率：X%　[正常]
ROE：X%
```
