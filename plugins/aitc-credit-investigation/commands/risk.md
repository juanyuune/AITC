# /risk — 快速風險評估

基於財務數據快速評估台灣上市公司的信用風險等級。

## 流程

1. 解析公司代碼與年度
2. 使用 xbrl-taiwan MCP 取得最新財務數字
3. 使用 skill: "ratio-analysis" 計算關鍵比率
4. 使用 skill: "trend-analysis" 評估趨勢
5. 綜合判斷風險等級（低 / 中 / 高）並說明依據

## 輸出格式

```
[公司] [年度] 快速風險評估

整體風險等級：[低 / 中 / 高]

主要依據：
✓ [正面指標]
⚠️ [需關注指標]

建議後續動作：[需要哪些額外資訊或分析]

資料來源：AITC XBRL 資料庫
⚠️ 本評估僅供初步參考，正式授信決策請經合格分析師完整審核。
```
