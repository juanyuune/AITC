# /risk — 快速風險評估

掃描台灣上市公司全年四季資料，依五大門檻評估信用風險等級。

## 流程

1. 解析公司代碼與年度
2. 取得 Q1–Q4 四季財務數字（分四次 MCP 呼叫）
3. Q4 單季數字以「全年累計 − 前三季累計」推算
4. 依五大門檻掃描：負債比率、流動比率、營業現金流、淨利、營收季減
5. 輸出交通燈號等級與旗標清單

## 風險等級

- 🟢 低風險：0 項旗標
- 🟡 中等風險：1–2 項旗標
- 🔴 高風險：3 項以上旗標
