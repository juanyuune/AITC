# /xbrl — 精確財務數字查詢

查詢 AITC XBRL 資料庫，取得指定公司、年度、季度的財務數字。

## 流程

1. 解析公司代碼/名稱、期間、財務項目
2. 若期間不明確，先呼叫 `list_periods` 確認可用期間
3. 使用 skill: "xbrl-query" 執行查詢
4. 格式化輸出，Q4 加注全年累計警示

## 範例

**輸入：** `xbrl 台泥 2024Q3 現金及約當現金`

**輸出：**
```
台灣水泥（1101）2024Q3 現金及約當現金

數值：新台幣 74,379,000,000 元
資料來源：AITC XBRL 資料庫 / 合併報表（CR）/ 2024/9/30

⚠️ 本資料僅供參考，財務決策請以公司正式公告及合格分析師審查為準。
```

**輸入：** `xbrl 2303 2024Q3`（不指定項目，回傳主要科目摘要）
