# /xbrl — XBRL 財務數字查詢

查詢台灣 FSC XBRL 資料庫，取得指定公司、年度、季度的精確財務數字。

## 流程

1. 解析參數（公司、期間、財務項目）
2. 若期間不明確，先呼叫 `list_periods` 確認可用期間
3. 使用 skill: "xbrl-query" 執行查詢
4. 格式化輸出，Q4 加注全年累計警示

## 範例

**輸入：** `/xbrl 台泥 2024Q1 現金及約當現金`

**輸出：**
```
台泥 2024年Q1 現金及約當現金：新台幣 83,196,535,000 元

資料來源：AITC XBRL 資料庫
⚠️ 本數據僅供參考，正式信用決策請經合格分析師複核。
```

**輸入：** `/xbrl 2303 2024Q3` （不指定項目，回傳全部）
