# /trend — 多季趨勢分析

分析台灣上市公司指定財務項目的多季走勢。

## 流程

1. 解析公司、財務項目、年度（或期間範圍）
2. 使用 skill: "trend-analysis" 查詢並分析趨勢
3. 呈現 Q1–Q4 走勢，計算季成長率，標注異常

## 範例

**輸入：** `/trend 台泥 營業收入 2024`

**輸出：**
```
台泥 2024年 營業收入走勢

Q1：NT$ XXX
Q2：NT$ XXX（較Q1：+X%）
Q3：NT$ XXX（較Q2：+X%）
Q4：NT$ XXX（全年累計，非單季數字）

整體判斷：穩定成長
```
