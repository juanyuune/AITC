# /peer — 同業比較

比較多家台灣上市公司同一財務指標，進行同業標竿分析。

## 流程

1. 解析主要公司、同業代碼清單、比較指標、期間
2. 使用 skill: "peer-comparison" 執行比較查詢
3. 排序並呈現同業排名與相對位置

## 範例

**輸入：** `/peer 1101 1102 1103 營業收入 2024Q3`

**輸出：**
```
2024Q3 營業收入 同業比較

1101 台泥：NT$ XXX　第 X 名
1102 亞泥：NT$ XXX　第 X 名
1103 嘉泥：NT$ XXX　第 X 名
```
