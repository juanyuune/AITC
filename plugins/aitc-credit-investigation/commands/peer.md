# /peer — 同業比較

比較多家台灣上市公司同一財務指標，進行同業標竿分析。

## 流程

1. 解析所有公司代碼、比較指標、期間
2. 呼叫 `compare_companies` MCP 工具（一次取回所有公司）
3. 若部分公司無資料，呼叫 `list_periods` 確認原因（未入庫 vs 此期間無資料）
4. 使用 skill: "peer-comparison" 排名並分析
5. 明確標注無資料的公司及原因

## 範例

**輸入：** `peer 1101 1102 1103 營業收入 2024Q3`

**輸出：**
```
同業比較｜營業收入｜2024Q3

  排名  公司      代碼   Q3 單季營業收入
  1     台灣水泥  1101   41,075 百萬元
  —     亞洲水泥  1102   無資料（資料庫未收錄）
  —     嘉新水泥  1103   無資料（資料庫未收錄）
```
